# CONNECTIQ

### Explainable Home and Last-Mile Connectivity Diagnosis

CONNECTIQ is a network diagnostics platform that measures connectivity and identifies possible network problems using transparent, rule-based analysis.

## Live Website

- Website: https://a3-ps015-tc241.onrender.com
- Diagnostic Dashboard: https://a3-ps015-tc241.onrender.com/dashboard.html
- API Documentation: https://a3-ps015-tc241.onrender.com/docs

## Key Features

- DNS resolution testing
- TCP connectivity measurements
- ICMP packet-loss measurement when supported
- Explainable diagnostic findings
- Evidence confidence and interpretation
- DNS failure simulation
- TCP failure simulation
- Packet-loss simulation
- Downloadable diagnostic reports

## Technology Stack

- Python
- FastAPI
- HTML, CSS and JavaScript
- Streamlit / Network diagnostic tools
